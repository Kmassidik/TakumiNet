# TakumiNet 3D art: copy-paste pack for ChatGPT

Copy one block at a time. Each block is one image to generate. Send them in order.

## How to use

1. Open a new chat and paste **Block 0** first.
2. Then paste one sheet block, wait for the image, and download it as PNG.
3. Name the file exactly as shown in the block title, for example `D1-devices.png`.
4. If the image has text, borders, a background, or cells of different sizes, say: *"Redo it: transparent background, no text, 6 equal cells, same scale."*
5. Do **not** upload any screenshot or icon from another product. Words only.

## Block 0: paste this first

```text
You are making original 3D artwork for a network-simulator web app called TakumiNet. I will send you one sheet request at a time. Rules for every sheet:
- The sheet is 1536 x 1024 pixels with exactly 6 cells in a 3 columns by 2 rows grid. Every cell is 512 x 512 and holds one object, centered, about 80 percent of the cell.
- Read order: left to right, top row first, then the bottom row.
- Transparent background (PNG with alpha). No text, letters, numbers, labels, borders, grid lines or watermarks anywhere.
- Same camera, lighting and colour palette on every sheet so all sheets look like one family.
- Make everything original. Do not copy any existing product icon or brand artwork.
- If I write "leave empty" for a cell, keep that cell completely transparent.
Reply "ready" and wait for the first sheet.
```
